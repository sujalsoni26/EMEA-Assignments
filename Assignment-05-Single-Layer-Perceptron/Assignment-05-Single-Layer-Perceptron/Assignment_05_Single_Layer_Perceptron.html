Assignment 5 — Single-Layer Perceptron with TensorFlow and Keras¶

Goal: build, train and analyse the simplest possible neural network: one neuron connected directly to the inputs.

Dataset: Breast Cancer Wisconsin (Diagnostic), UCI. 569 tumour samples, each with 30 numeric features computed from a digitised image of a fine-needle aspirate (cell-nucleus radius, texture, concavity and so on). The task is binary classification: malignant vs benign, which suits a single-layer perceptron well because the classes are close to linearly separable.

1. Prepare the dataset¶

scikit-learn ships an exact copy of the UCI dataset, so nothing needs to be downloaded. In the raw encoding 0 = malignant and 1 = benign. I flip it so that 1 = malignant, because the class we want to detect should be the "positive" class. That way recall means "share of cancers detected".

The data is clean, with no missing values and no duplicates. It is moderately imbalanced (37% malignant). The feature scales differ enormously, e.g. mean area is around 650 while mean smoothness is around 0.1.

Split. 60% train / 20% validation / 20% test, all stratified to keep the 37/63 class ratio:

  • train: used to update the weights;
  • validation: monitored after every epoch to watch for over- or underfitting;
  • test: touched once, at the very end.

Scaling. A perceptron computes w·x + b. With unscaled inputs, area (around 10³) would produce huge gradients for its weight while smoothness (around 10⁻¹) would barely move, so gradient descent would zig-zag and converge slowly. StandardScaler (mean 0, sd 1) is fitted on the training set only and then applied to validation and test.

2. Design the perceptron¶

A single-layer perceptron is one neuron. It takes a weighted sum of all inputs plus a bias and passes the result through an activation function:

$$\hat{y} \;=\; \sigma\!\left(\sum_{i=1}^{30} w_i x_i + b\right) \;=\; \sigma(\mathbf{w}^\top\mathbf{x} + b), \qquad \sigma(z) = \frac{1}{1 + e^{-z}}$$

 x₁ ──w₁──┐
 x₂ ──w₂──┤
  ⋮        ├──► z = Σ wᵢxᵢ + b ──► sigmoid(z) ──► P(malignant) ∈ (0, 1) ──► ≥ 0.5 ? malignant : benign
 x₃₀─w₃₀──┘

Choice of activation: sigmoid.

  • The output must be a probability for one binary label. Sigmoid squashes any real number into (0, 1), which is exactly what is needed.
  • It is smooth and differentiable, so the model can be trained by gradient descent. Rosenblatt's original step activation (output 0 or 1) has a gradient of zero almost everywhere, so backpropagation cannot use it. Section 6.1 shows this in practice.
  • It pairs naturally with binary cross-entropy. The combined gradient simplifies to (ŷ − y)·x, which is well-behaved.
  • ReLU or tanh would be wrong for this output: ReLU is unbounded and tanh outputs (−1, 1). Those activations belong in hidden layers, and this model has none.

With 30 inputs the model has 30 weights + 1 bias = 31 trainable parameters.

In [5]:
def build_perceptron(n_inputs=30, activation="sigmoid", name="single_layer_perceptron"):
    return keras.Sequential([
        keras.Input(shape=(n_inputs,), name="features"),
        keras.layers.Dense(1, activation=activation, name="output_neuron"),
    ], name=name)

model = build_perceptron()
model.summary()

Compiling the model means choosing how it learns:

Component Choice Why
Loss function binary_crossentropy The right loss for a probability output with a 0/1 label (details in Section 7)
Optimizer Adam, learning rate 0.01 Adaptive per-weight step sizes, so it converges reliably within 25 epochs (compared with others in Section 6.2)
Metrics accuracy, precision, recall, AUC Monitored only. They do not affect training
Batch size 16 341 training samples / 16 = 22 weight updates per epoch

3. Train for 25 epochs¶

One epoch is one full pass over the 341 training samples. With a batch size of 16 that is 22 gradient updates per epoch, and 550 updates across all 25 epochs. After each epoch Keras reports the metrics on the training and validation sets.

Reading the curves

  • The loss falls steeply in the first 3–5 epochs, as the weights move from their random start toward a good decision boundary, and then levels off.
  • Training and validation curves stay close together for all 25 epochs. Validation loss is still (slowly) decreasing at epoch 25 and never climbs back up, so within these 25 epochs there is no sign of overfitting. That is expected: a model with only 31 parameters has very little capacity to memorise. Section 6.3 looks at what happens with much longer training.
  • Accuracy settles at a high level after only a few epochs, which shows that the two classes are close to linearly separable in this 30-dimensional feature space.

What did the neuron learn?¶

Because the inputs are standardised, each weight shows how strongly one standard deviation of that feature pushes the prediction toward malignant (positive weight) or benign (negative weight). A single perceptron is fully interpretable in this way.

The largest positive weights belong to texture (worst texture), size (worst perimeter, mean area, mean radius) and shape irregularity (mean concavity, worst concave points, worst smoothness). This agrees with the clinical picture that malignant nuclei are larger, more irregular and more heterogeneous.

A few features that are individually higher in malignant tumours (e.g. worst compactness) get small negative weights. This is not a contradiction. Many of the 30 features are strongly correlated (radius, perimeter and area describe almost the same thing), so the neuron spreads credit across them and uses some as corrections to others. Weights of correlated features should be read as a group, not one by one.

6. Experiments: the role of each design choice¶

6.1 Activation function: why not the original step function?¶

Rosenblatt's 1958 perceptron used a step activation, ŷ = 1 if w·x + b ≥ 0 else 0, with the perceptron learning rule w ← w + η(y − ŷ)x. It only learns from misclassified points and outputs hard 0/1 labels. Below, the same one-neuron model is trained for 25 epochs with the step rule (NumPy) and with sigmoid + cross-entropy + gradient descent (Keras, plain SGD so the two are comparable).

In [13]:
def train_step_perceptron(X, y, Xv, yv, epochs=25, lr=0.01, seed=SEED):
    rng = np.random.default_rng(seed)
    w, b = rng.normal(0, 0.05, X.shape[1]), 0.0
    tr_acc, va_acc = [], []
    for _ in range(epochs):
        for i in rng.permutation(len(X)):
            y_hat = 1.0 if X[i] @ w + b >= 0 else 0.0
            w += lr * (y[i] - y_hat) * X[i]
            b += lr * (y[i] - y_hat)
        tr_acc.append(((X @ w + b >= 0) == y).mean()); va_acc.append(((Xv @ w + b >= 0) == yv).mean())
    return np.array(tr_acc), np.array(va_acc)

The step perceptron can still learn a linear boundary, but:

  • when the data is not perfectly linearly separable (and here it is not), the perceptron rule never converges. The weights keep jumping every time a point is misclassified, so accuracy oscillates from epoch to epoch;
  • it outputs only hard 0/1 labels, with no measure of confidence, so we cannot rank patients by risk, compute ROC-AUC, or tune a threshold.

The sigmoid gives a smooth, differentiable output, so cross-entropy can be minimised by gradient descent. Training is stable, and every prediction comes with a probability.

7. Roles of the activation function, loss function, optimizer and epochs¶

Component Role in general What was used here and why
Activation function Turns the neuron's weighted sum z into its output. It sets the output range and (in deeper networks) adds non-linearity. It must be differentiable for gradient-based training. Sigmoid, σ(z) = 1/(1+e⁻ᶻ). Maps z to a probability in (0, 1) for the single binary output. Unlike the step function it is differentiable and gives a confidence score (Section 6.1).
Loss function A single number measuring how wrong the predictions are. Training means minimising it, and its gradient tells each weight which way to move. Binary cross-entropy, L = −[y·log ŷ + (1−y)·log(1−ŷ)]. It is the negative log-likelihood of a Bernoulli label, so minimising it gives well-calibrated probabilities. It punishes confident mistakes very heavily (as ŷ → 0 for a true 1, L → ∞). With a sigmoid output its gradient is simply (ŷ − y)·x, and the problem is convex. MSE would also train, but its gradients vanish when the sigmoid saturates.
Optimizer The algorithm that uses the gradient to update the weights: w ← w − η·(update direction). It controls step size, momentum and per-parameter adaptation. Adam (learning rate 0.01). It combines momentum (a running mean of gradients) with per-weight adaptive step sizes (a running mean of squared gradients), so it converged fastest in Section 6.2.
Epochs One epoch is one full pass over the training set. More epochs mean more updates. Too few leads to underfitting (not yet converged); too many can lead to overfitting. Validation loss shows which regime you are in. 25 epochs × 22 mini-batches = 550 updates. Section 6.3 shows this is close to the validation-loss minimum (epoch 32), and that training far longer starts to overfit mildly even for this tiny model.
(Batch size) Number of samples per gradient update. Small batches give noisier but more frequent updates. 16

8. Conclusion¶

  • Data: I used the Breast Cancer Wisconsin dataset (569 tumours, 30 features), relabelled so that 1 = malignant, split 60/20/20 with stratification, and standardised with statistics from the training set only.
  • Architecture: a single Dense neuron with a sigmoid activation, 31 trainable parameters, trained with binary cross-entropy and the Adam optimizer for 25 epochs.
  • Training: loss dropped from 0.35 to 0.06 (training) and from 0.19 to 0.07 (validation). Most of the learning happened in the first 5 epochs, and the training and validation curves stayed close, so there was no overfitting within 25 epochs.
  • Test performance (114 unseen tumours): accuracy 96.5%, precision 0.95, recall 0.95, F1 0.95, ROC-AUC 0.996. Only 2 of 42 malignant tumours were missed, and only 2 of 72 benign tumours were falsely flagged.
  • Experiments:
    • A step activation trains, but it oscillates and gives no probabilities. The differentiable sigmoid gives smooth convergence and calibrated confidence.
    • Adaptive optimizers (Adam, RMSprop) converge much faster than plain SGD in the same 25 epochs.
    • 25 epochs is close to the validation-loss optimum. Far longer training slowly overfits.
  • Limitation: a single-layer perceptron can only learn a linear decision boundary. It works very well here because the data is nearly linearly separable, but it would fail on problems that need curved boundaries, which is the motivation for the multi-layer perceptrons in Assignment 6. In a real screening setting I would also lower the decision threshold below 0.5 to trade some precision for even higher recall, since a missed cancer costs far more than a false alarm.
